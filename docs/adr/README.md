# Registros de decisões arquiteturais

Um ADR registra uma decisão técnica que seja difícil de reverter, surpreendente sem contexto e resultado de uma escolha real entre alternativas.

Use nomes sequenciais:

```text
0001-titulo-curto-da-decisao.md
0002-outra-decisao.md
```

Estrutura sugerida:

```markdown
# Título

## Status

Proposta, aceita, substituída ou rejeitada.

## Contexto

Qual problema exige uma decisão?

## Alternativas consideradas

Quais opções foram avaliadas?

## Decisão

O que foi escolhido e por quê?

## Consequências

Quais benefícios, custos e limitações foram aceitos?
```

Não use ADR para tarefas rotineiras ou decisões facilmente reversíveis.
