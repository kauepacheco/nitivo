# Domain docs

O Nitivo possui um único contexto de domínio.

- Leia CONTEXT.md na raiz antes de explorar ou descrever o domínio.
- Consulte os ADRs relevantes em docs/adr/ antes de propor decisões arquiteturais.
- Use o vocabulário do glossário em specs, issues, código e testes.
- Mostre divergências entre código, documentos e decisões; não substitua uma fonte silenciosamente.
- Registre termos resolvidos no glossário e decisões arquiteturais que atendam aos critérios do projeto nos ADRs.
- Se precisar de um termo ainda ausente, confira se é um conceito novo ou apenas outro nome para um conceito existente.

Estas orientações complementam as fontes e regras de AGENTS.md. Não criar divisões de contexto ou documentos antecipadamente sem necessidade.
