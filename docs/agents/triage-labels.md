# Triage labels

| Papel da skill | Rótulo no GitHub | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Precisa de avaliação do mantenedor. |
| needs-info | needs-info | Aguarda informações adicionais. |
| ready-for-agent | ready-for-agent | Especificação pronta para execução por agente. |
| ready-for-human | ready-for-human | Requer ação humana. |
| wontfix | wontfix | Não será executado. |

Use este mapeamento quando uma skill indicar um papel de triagem. Estar ready-for-agent não substitui as instruções do proprietário sobre quando iniciar implementação.
