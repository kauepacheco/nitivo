# Skills do Nitivo

Este diretório é reservado às skills de agente específicas do projeto e compartilhadas por Git entre os computadores de desenvolvimento.

Conjunto selecionado para avaliação:

- `domain-modeling`;
- `grilling`;
- `grill-with-docs`;
- `tdd`;
- `diagnosing-bugs`;
- `code-review`;
- `writing-for-agents`.

As skills ainda não estão instaladas. Antes de adicioná-las, devem ser revisados o `SKILL.md`, as referências, os scripts e a licença de cada uma. Dependências entre skills também devem ser preservadas.
